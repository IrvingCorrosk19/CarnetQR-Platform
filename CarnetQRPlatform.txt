=== SECCIÓN 3: ARQUITECTURA MULTI-TENANT ===

Implementa multi-empresa estricto (multi-tenant) en CarnetQR Platform.

Reglas:
- Cada empresa (Institution) es un tenant aislado
- Todo dato operativo pertenece a una Institution
- Un usuario interno pertenece a una sola Institution
- El SuperAdmin (QL Services) puede crear empresas, pero no acceder a sus datos operativos
- El sistema debe impedir cualquier acceso cruzado

Implementación:
- Entidad Institution
- ITenantProvider para resolver InstitutionId desde el usuario autenticado
- Middleware que valide y establezca el tenant actual
- EF Core Global Query Filters por InstitutionId
- Protección server-side en escrituras (forzar InstitutionId)
- Tests unitarios básicos del TenantProvider

Entrega:
- Código completo (middleware, provider, filtros, ejemplos)
- Justificación técnica breve
